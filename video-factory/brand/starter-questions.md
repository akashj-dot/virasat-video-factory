# Virasat video brief — starter questions

Ask these before starting any build in this factory. This replaces the
generic "topic / language / tone / orientation / source material" brief —
use this exact sequence instead.

1. **New video or converting an existing IG post to a reel?**
   - If **new video**: what's the video about?
   - If **converting an existing IG post**: share the Canva design URL.
2. **Narration language** — Hindi / English / Hinglish
3. **Tone** — one of:
   - Documentary / Investigative
   - Cautionary / Consequence-led
   - Empathetic / Human-story-anchored
   - Data-led / Stat-shock
   - Practical / Checklist-guide
4. **BGM audio file location** — where's the background music file?
5. **Orientation** — vertical (9:16) or horizontal (16:9)
6. **Theme** — Dark or Light (picks `brand/virasat-frame-dark.md` vs `brand/virasat-frame-light.md`, see `brand/README.md`)
7. **Source material** — do you already have notes/links/data, or should Claude research public sources itself?

## Notes for whoever's building

- Don't skip straight to building on a vague ask ("make a video about X") — always run this full sequence first, every time, even for a quick one-off.
- Brand palette, logo overlay, and the closing waitlist card are applied automatically per `brand/README.md` — no need to ask about those; they're defaults, not brief questions.
- Q1's branch matters: a "converting an existing IG post" answer means the video's structure/copy should follow the existing Canva design rather than being written from scratch — read the design first (via the Canva connector) before treating this like a from-scratch brief.
